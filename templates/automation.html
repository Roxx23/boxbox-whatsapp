Automation

Automatically send WhatsApp messages when Shopify events happen.

Shopify Webhook Setup

Go to Shopify Admin → Settings → Notifications → Webhooks and add these webhooks:

https://dashboard.boxbox.in/shopify/webhook/order-create orders/create
https://dashboard.boxbox.in/shopify/webhook/fulfillment orders/fulfilled
https://dashboard.boxbox.in/shopify/webhook/cart-create checkouts/create

Optional: Set SHOPIFY_WEBHOOK_SECRET in your .env to verify webhook signatures.
