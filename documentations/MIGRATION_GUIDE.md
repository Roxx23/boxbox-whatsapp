# 🔄 Migration Guide - Version 2.0.0

## For Existing Users

If you're upgrading from the previous version, follow these steps:

---

## ⚠️ **IMPORTANT: Breaking Changes**

The app will **NOT start** without proper configuration. This is intentional for security.

---

## 📋 Step-by-Step Migration

### Step 1: Backup Your Current Setup

```bash
# Backup your current .env file (if you have one)
cp .env .env.backup

# Backup your database/logs
cp logs.csv logs.csv.backup
```

### Step 2: Pull Latest Changes

```bash
git pull origin main
# or download the latest code
```

### Step 3: Run Setup Script

```bash
python setup.py
```

The setup script will:
- ✅ Create `.env` from `.env.example`
- ✅ Generate a secure `SECRET_KEY`
- ✅ Check for required dependencies

### Step 4: Configure Your Credentials

Edit the `.env` file and add your WhatsApp API credentials:

```env
# Required - Get from Meta Business Suite
WHATSAPP_ACCESS_TOKEN=your_actual_token_here
WHATSAPP_PHONE_NUMBER_ID=your_actual_phone_id_here
WABA_ID=your_actual_waba_id_here

# Required - Already generated by setup.py
SECRET_KEY=<already_set>

# Optional - Adjust as needed
FLASK_DEBUG=False
FLASK_HOST=127.0.0.1
FLASK_PORT=5000

# Optional - Adjust based on your API tier
RATE_LIMIT_REQUESTS=20
RATE_LIMIT_WINDOW=1.0
MESSAGE_QUEUE_WORKERS=1
```

### Step 5: Test the Application

```bash
python app.py
```

You should see:
```
✅ Message queue started successfully
⚙️ Rate limit: 20 requests per 1.0s with 1 worker(s)
====================================================
🚀 Starting WhatsApp Bulk Sender
🌐 Host: 127.0.0.1:5000
🐛 Debug Mode: False
📊 Queue monitoring: http://127.0.0.1:5000/queue-status
📈 Queue stats API: http://127.0.0.1:5000/queue-stats
====================================================
```

### Step 6: Verify Functionality

1. **Upload CSV Test:**
   - Try uploading a valid CSV
   - Try uploading an empty CSV (should be rejected)
   - Try uploading a file with invalid phone numbers (should show which ones are invalid)

2. **Message Sending Test:**
   - Send a test message to verify API connection
   - Check queue status at `/queue-status`

3. **Template Test:**
   - Try creating a template
   - Verify it works with your credentials

## 🔧 What Changed?

### Required Actions:

1. **Environment Variables Now Required**
   - `WHATSAPP_ACCESS_TOKEN` - Required
   - `WHATSAPP_PHONE_NUMBER_ID` - Required
   - `WABA_ID` - Required
   - `SECRET_KEY` - Required (auto-generated by setup.py)

2. **Debug Mode Defaults to False**
   - Production-safe by default
   - Set `FLASK_DEBUG=True` only for development

3. **Host Defaults to 127.0.0.1**
   - No longer exposed to all interfaces
   - Use reverse proxy for external access

### Optional Configurations:

```env
# Server settings
FLASK_DEBUG=False
FLASK_HOST=127.0.0.1
FLASK_PORT=5000

# Rate limiting (adjust for your API tier)
RATE_LIMIT_REQUESTS=20
RATE_LIMIT_WINDOW=1.0
MESSAGE_QUEUE_WORKERS=1

# Logging
LOG_FILE=logs.csv
```

## 🚨 Troubleshooting

### Error: "Missing required environment variables"

**Solution:**
```bash
# Make sure .env file exists
ls -la .env

# Check it has all required variables
cat .env

# Run setup script if needed
python setup.py
```

### Error: "SECRET_KEY must be set"

**Solution:**
```bash
# Generate a new secret key
python -c "import secrets; print(secrets.token_hex(32))"

# Add it to .env file
echo "SECRET_KEY=<generated_key>" >> .env
```

### App Won't Start

**Check:**
1. `.env` file exists in root directory
2. All required variables are set
3. No typos in variable names
4. Installed all dependencies: `pip install -r requirements.txt`

### "Invalid phone number" Errors After Upload

**This is expected!** The new validation catches invalid numbers before API calls.

**What to do:**
1. Check the error message - it shows which rows have invalid numbers
2. Fix the phone numbers in your CSV
3. Upload again

**Valid formats:**
- `+919876543210` ✅
- `919876543210` ✅
- `9876543210` ✅

**Invalid formats:**
- `123` ❌ (too short)
- `abc123` ❌ (non-numeric)
- Empty ❌
